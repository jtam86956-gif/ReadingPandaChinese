# HSK 3.0 考试大纲（参考数据）

本目录存放 **HSK 3.0《考试大纲》** 的解析结果，作为 Panda News 难度分级的**参考补充**，
**不替换**主词表（主分级仍用 `data/hsk/HSK{1..7}.txt`，来自 GF 0025—2021《等级标准》）。

## 来源

- **文件**：`raw/hsk30_exam_syllabus_korea.pdf`（4.2 MB，317 页）
- **出处**：HSK Korea 发布的《HSK 考试大纲 / Syllabus for the Chinese Proficiency Test》，
  2025-11 发布、2026-07 实施。由中外语言交流合作中心（语合中心）/ 汉考国际制定。
  下载页：https://www.hsk-korea.co.kr/resources/HSK3.0%EC%8B%9C%ED%97%98%EA%B0%9C%EC%9A%94_%EA%B8%89%EC%88%98%EB%B3%84%EB%8B%A8%EC%96%B4_%EC%96%B4%EB%B2%95.pdf
- **解析脚本**：`scripts/parse_hsk30_exam_syllabus.py`（依赖 `pypdf`，`pip install --user pypdf`）。
- **输出**：`hsk30_exam_syllabus.tsv`

## 与主词表（GF 0025—2021）的关系

两份都是权威来源，但是**不同的文档**：

| 维度 | 主词表（已用于分级） | 本参考（考试大纲） |
|---|---|---|
| 文档 | 《国际中文教育中文水平等级标准》GF 0025—2021 | HSK 3.0《考试大纲》2025-11 |
| 性质 | 国家语言文字规范（等级标准） | 实际考试范围（考试大纲） |
| 总词条 | 11092 | 11000 |
| 各级累积 | 500 / 1272 / 2245 / 3245 / 4316 / 5456 / 11092 | **300 / 500 / 1000 / 2000 / 3600 / 5400 / 11000** |
| 获取方式 | 汉考国际官方接口（结构化） | 官方 PDF（本脚本解析） |

> ⚠️ **等级号不能直接横向比较**：两者各级累积词汇量不同（如一级 500 vs 300），
> 等级刻度是重新画过的。同一个词在两份表里等级号不同（如「家属」标准 3 级 / 考试 6 级）
> 多为刻度差异，不代表真矛盾。

## 解析结果校验

- 解析到 **11000 条**，序号 1..11000 **连续无缺** ✓
- 主级分布（累积）与官方公布完全一致：300 / 500 / 1000 / 2000 / 3600 / 5400 / 11000 ✓
- 七—九级合并标注为 `7-9`，本脚本记为 `primary=7`（与主词表 `HSK7.txt` 的「高等」约定一致）。

## 对照分析（考试大纲 vs GF 0025—2021）

基于词形的精确匹配（未做归一化）：

| 指标 | 数量 |
|---|---|
| 考试大纲词数（去重） | 10940 |
| 标准词数（去重） | 10959 |
| 两表共有 | 9641 |
| 考试大纲独有 | 1299 |
| 标准独有 | 1318 |

> ⚠️ 「独有」数偏高，相当一部分是**同一词的书写形式不同**，并非真正的词汇差异，例如：
> - 标准 `们（朋友们）`（带括注） vs 考试 `们`
> - 标准 `一下儿` / `一下子` vs 考试 `一下`
> - 标准含大量构式条目（`…分之…`、`…极了` 等带省略号的格式），考试大纲未单列。
>
> 做归一化（去掉括注、儿化后缀、省略号构式）后，真实差异会明显缩小。本报告暂保留原始匹配数。

**等级一致性**（共有词中，考试主级 == 标准最低级）：5638 / 9641 ≈ **58.5%**。
不一致主要来自上述等级刻度差异，而非错误。

## 接入状态（已生效）

考试大纲已接入 `pipeline/nlp/grade.py` 的生词判定（非仅存档）：

- `word_level(word)` 返回**有效已知等级** = GF 标准等级 与 考试大纲主级的较低者
  （任一权威来源收录即视为已学），统一用于文章分级与生词判定。
- 这修正了 GF 因词形差异（括注 `们（朋友们）` / 下标 `本1`）导致的漏匹配，
  也纠正了 GF 对部分词的等级高估（如 `羡慕`：GF 7 → 考试 4），减少假生词。
- `word_cross_levels(word)` 暴露跨级标注，写入 manifest 的 token 与 `new_vocab`
  （字段 `cross`，无则省略），供阅读器标记「多级复现词」。
- 考试大纲文件缺失时**优雅降级**为纯 GF 标准，不影响主路径。

## 本参考的独特价值

1. **跨级标注（102 条）**：考试大纲独有的信息——标注一个词在考试中跨级出现，
   如 `半` 标 `1（4）`（1 级考、关联 4 级）、`好` 标 `1（2）（4）`。
   主词表没有这个维度，可用于：判断一个「低级词」是否实际上在高级别复现、
   辅助生词判定的置信度。
   - 跨级标注按主级分布：1级14 / 2级21 / 3级21 / 4级31 / 5级12 / 6级2 / 7级1。
2. **补充覆盖率**：考试大纲的 1299 个独有词（归一化后更少）可用于填补主词表的
   「未收录」空白，减少分级时 `hsk=None` 的 token。
3. **第二来源校验**：与主词表互为印证，发现主词表可能的遗漏或格式问题。

## 字段说明（`hsk30_exam_syllabus.tsv`）

| 列 | 含义 |
|---|---|
| `no` | 大纲序号 1..11000 |
| `primary` | 主级 1-7（7 = 七—九级高等 band） |
| `cross` | 跨级标注，逗号分隔（如 `2,4`），无则空 |
| `word` | 词语（可能带同形词下标如 `本1`，或括注如 `没（有）`） |
| `pinyin` | 拼音 |
| `pos` | 词性 |

