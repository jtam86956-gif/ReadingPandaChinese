# Panda News（熊猫新闻）产品需求文档（PRD）

> 一个「通过阅读真实中文资讯学习中文」的产品，借鉴 `hehonghui/awesome-english-ebooks` 的「内容流水线 + Git 分发」模式。
>
> 版本：v0.3（内容红线已锁定）｜日期：2026-11-12｜状态：仅公版内容 + 极简阅读器

---

## 1. 背景与目标

### 1.1 背景
- `awesome-english-ebooks` 证明了一个模式成立：**用 Calibre 自动抓取外刊 → 转多格式 → Git 仓库分发 → 配合阅读器**，为英语学习者提供持续、免费、零摩擦的真实阅读材料，收获数万 Star。
- 中文作为第二语言（CSL，Chinese as a Second Language）的学习市场缺少同类产品：现有材料要么是教材体（枯燥、非真实语境），要么散落在各新闻站（无注音、无分词、无翻译、无生词管理），学习闭环断裂。
- 大模型（LLM）与中文 TTS 的成熟，让「逐句讲解、自动注音、智能分级」的成本降到可以产品化。

### 1.2 产品目标
1. **持续供给**：自动化流水线每日产出带注音、分词、翻译、音频的真实中文阅读材料。
2. **沉浸阅读**：阅读器支持「点字出拼音/释义/笔顺、点词查义、整句翻译与 AI 讲解、朗读」。
3. **学习闭环**：生词本 + 间隔重复（SRS）复习 + 学习统计，形成「读 → 记 → 复习 → 测」闭环。
4. **低冷启动成本**：内容仓库天然免费托管，MVP 阶段不做重后端，先验证内容与阅读体验。

### 1.3 非目标（MVP 阶段不做）
- 不做社区/社交（评论、关注、打卡分享）。
- 不做 UGC（用户上传内容）。
- 不做直播课 / 真人外教。
- 不做写作批改、口语评测（留待后续版本）。
- 不做新闻门户 / 泛资讯浏览（内容主线是难度可控的分级精读）。

## 2. 产品定位与一句话价值

**定位**：面向 HSK 5–9 中高级学习者的「分级精读 + 生词复习」产品。

**一句话价值**：*每天一篇刚好够得着的中文——点一下就会，读着读着就记住了。*

**定位边界（MVP 必须守住）**：
- **服务谁**：只有一个主用户——HSK 5–9 的成年中文学习者。所有取舍以他为准。
- **提供什么**：**难度可控的精读材料**，不是资讯聚合，也不是教材替代品。
- **不做什么**：不做新闻门户、不做泛资讯浏览、不为 K12 单独做设计决策。
- **「真实」的定义**：真实语境（自然表达、非教材腔），**不等于必须来自新闻**。

> 定位推导依据（2026-11-12 实测）：内容难度必须与目标用户匹配。当前公版书节选实测落在
> HSK 5–7 区间，正好服务中高级学习者；过易材料（HSK 2–4）不构成本产品的差异化价值。

**对标关系**：

| 维度 | awesome-english-ebooks | Panda News（本产品） |
|---|---|---|
| 学习者 | 中国人学英语 | HSK 2–4 成年中文学习者（CSL） |
| 内容 | 英语外刊（经济学人等） | 分级短文（主）/ 公版经典改编 / 真实资讯（进阶） |
| 仓库角色 | 内容分发（只读下载） | 内容分发 + 元数据索引（被 App 消费） |
| 阅读器 | 第三方（英阅阅读器） | 自研（Web 优先 → App） |
| 学习辅助 | 无（阅读器侧提供） | 内置：注音/分词/翻译/AI 讲解/生词本/SRS |

## 3. 目标用户与画像

### 3.1 核心用户（MVP 唯一主用户）：HSK 5–9 中高级学习者
- **HSK 5–9 级考生 / 学习者**：需要真实语境输入，教材不够。
- **在华工作/留学的外国人**：需要快速提升实用阅读能力。
- **中国文化 / 时事爱好者**：想直接读中文原文，而不是翻译稿。

> 产品设计、内容难度、功能优先级，一律以这一群体的需求为准。

### 3.2 次级用户：K12 与华人子女（MVP 不为其单独设计）
- 小学高年级–初中生：拓展阅读、积累词汇。
- 海外华人子女的家长：希望孩子保持中文阅读能力。
- 处理方式：共用同一内容池，后续以 Kids 模式（话题过滤 + 等级限高）承接，**不进入 MVP 设计决策**。

### 3.3 用户画像（典型）
> **Lisa，28 岁，美国人，在上海工作，HSK 4 级。**
> 每天通勤 30 分钟，想读真实中文但《人民日报》太难、教材太无聊。她希望：打开 App 有一篇「刚好够得着」的短文，点不认识的字能立刻看到拼音和意思，遇到的生词自动收进生词本，第二天复习。

> **陈先生，40 岁，温哥华华人，女儿 10 岁。**
> 想让女儿保持中文阅读，需要按难度分级、带拼音、有朗读音频的材料，最好是孩子感兴趣的话题（动物、科学、故事）。

## 4. 核心场景与用户旅程

### 4.1 核心场景
| # | 场景 | 触发 | 期望结果 |
|---|---|---|---|
| S1 | 每日一读 | 用户打开 App | 推荐 1–3 篇匹配其等级的短文，5–10 分钟读完 |
| S2 | 读懂难字 | 阅读中遇到生字 | 点字 → 拼音（不做释义/笔顺/组词/例句） |
| S3 | ~~读懂难句~~ | — | **已移除**：不做整句翻译、不做 AI 讲解 |
| S4 | 积累生词 | 想记住这个词 | 一键加入生词本，自动记录上下文 |
| S5 | 复习巩固 | 生词本有积累 | SRS 推送复习卡片，记住/忘了标记 |
| S6 | 追踪进步 | 想看到成长 | 学习统计：阅读篇数、时长、生词掌握数、等级曲线 |
| S7 | 离线/多端 | 通勤无网 | 已读/已下载内容离线可用；进度多端同步 |

### 4.2 主用户旅程（S1→S2→S4→S5）
```
打开 App → 今日推荐 → 选一篇 → 沉浸式阅读
  → 遇生字：点字看拼音 → 遇生词：看极简释义 / 加入生词本
  → 读完 → 统计更新
  → 次日：SRS 提醒复习昨日生词 → 继续读新一篇
```

## 5. 功能需求

按模块组织，优先级采用 **MoSCoW**：Must（必须）/ Should（应该）/ Could（可以）/ Won't（暂不）。

### 5.1 内容供给（系统侧，用户无感知）
| 编号 | 功能 | 优先级 | 说明 |
|---|---|---|---|
| C-01 | 内容抓取（仅公版） | Must | 每日定时抓取**公版/自有**内容源，去重、清洗正文；**只做抓取与原样展示，不改写、不附加生成内容** |
| C-02 | 公版/分级内容入库 | Must | 公版经典 + 自建分级短文，按等级组织 |
| C-03 | 中文 NLP 加工 | Must | 注音（pypinyin）、分词、词性、难度分级（HSK/字频） |
| C-04 | ~~翻译生成~~ | Won't | **红线禁止**：不生成生词释义、不做整句翻译、不接外部词典 API |
| C-05 | TTS 音频生成 | Should | 每篇生成标准普通话朗读音频（整段 + 分句） |
| C-06 | 多格式产物 | Should | 每篇输出 `.json`（结构化，供 App）+ `.epub`（带注音）+ `.pdf` |
| C-07 | 内容审核 | Should | 敏感词/合规过滤（资讯源尤其重要） |
| C-08 | 内容目录 API | Must | 按日期/等级/分类列出文章、取单篇 manifest |

### 5.2 阅读器（核心体验）

| R-05 | ~~整句翻译~~ | Won't | **红线禁止** |
| R-06 | ~~AI 句子讲解~~ | Won't | **红线禁止**：不对新闻附加任何生成式注释 |

| R-10 | 划线/笔记 | Should | 高亮句子、写笔记 |

## 6. 内容策略

### 6.1 内容来源（合规优先，规避 DMCA 风险）
| 来源类型 | 具体来源 | 版权处理 | 优先级 |
|---|---|---|---|
| **公版书** | **文学**：鲁迅、朱自清、胡适等；**社科**：胡适《容忍与自由》、陈独秀《敬告青年》、胡适《文学改良刍议》、孙中山《民报发刊词》等（作者逝世 >50 年） | 公有领域，自由使用 | **高（唯一合规内容源）** |
| **自建分级短文** | 自建/编辑撰写，按 HSK 等级控词、控长（300–600 字） | 自有版权 | **高（MVP 主线）** |
| CC 授权内容 | 维基文库、CC-BY 博客 | 按授权署名 | 中 |
| ~~公开新闻 RSS~~ | ~~BBC 中文、联合早报、德国之声中文等~~ | 非公版，正文受版权保护 | **Won't（停用）** |
| ~~政府/机构公开~~ | ~~新华社、人民日报 RSS~~ | 非公版，需授权 | **Won't（停用）** |
| 播客音频 | 公开 RSS 或 TTS 生成 | TTS 自有；播客注明来源 | 低 |

> **内容红线（v0.3）**：只抓取**公版或自有**内容，代码只做抓取与原样展示；
> 不改写原文、不附加任何生成式释义或注释。非公版内容（含商业新闻、政府媒体）一律不接入。

> **主线变更（v0.2）**：内容主线由「真实新闻」改为「难度可控的分级短文 + 公版改编」。
> 原因：新闻难度不可控（实测 level 全为 6、最长 5060 字），无法兑现「读得懂」的承诺。
> **v0.3 追加**：非公版新闻源按版权红线**全部停用**。
> **篇幅硬约束**：主线的每篇 300–600 字，对应「5–10 分钟读完」。

### 6.2 难度分级
采用 **难词密度法**，输出 1–9 级（本产品内容集中在 5–9）：

- **难词** = HSK 6 级及以上的字 + 权威词表未收录的字。
- 计算难词在全文汉字中的**占比**，按密度定级：**12% 对应 5 级，每多 6 个百分点升一级**，上限 9 级。
- 再做**长度修正**：字数超过该等级上限（5 级 800 字、6 级 1000 字、7 级 1200 字…）时上调一级，避免「词不难但读不完」。
- 每篇打 `level` 标签（1–9）。分级实现见 `pipeline/nlp/grade.py::grade_level`。

> **为什么不用「HSK 累积覆盖率 ≥ 95%」**：实测近代白话作品（鲁迅、胡适等）的未收录字占 7%–28%，
> 覆盖率几乎不可能达到 95%，全部文章会被压到同一档，失去区分度。改用难词密度后，
> 同一批 14 篇能分出 5/6/7/9 四档。

> **8、9 级的含义**：权威词表把七—九级合并为「高等」，因此 8、9 不是词表级别，
> 而是「高于高等的密度档」——未收录字与高等词越密集，档位越高。

> **废弃做法**：曾用「取全篇最高 HSK 级」定级，导致出现一个人名或成语就把整篇顶到 6 级，
> 5 篇实测全部 output 6，分级完全失效。现以密度为主，单点生僻词不再能左右结果。

## 8. 学习闭环设计（核心差异化）

```
阅读（输入） ──点词──▶ 生词本（记录上下文）
   │                      │
   │                      ▼
   │                  SRS 复习（间隔重复）
   │                      │
   ▼                      ▼
 统计反馈 ◀────────── 掌握度更新
   │
   ▼
 推荐更难/更匹配的内容（难度自适应）
```

- **SRS 算法**：采用简化版 SM-2（与 Anki 同源），间隔：1d → 3d → 7d → 14d → 30d，根据反馈（认识/模糊/忘了）调整。
- **上下文记忆**：每个生词永远绑定「第一次遇到它的那句话」，复习时可跳回原文重读——这是真实语境学习的关键。

## 9. 非功能需求

| 维度 | 要求 |
|---|---|
| 性能 | 阅读器首屏 < 1.5s（Web）；点字响应 < 200ms；整篇加载 < 2s |
| 可用性 | 支持简体中文；UI 支持中/英双语切换（照顾外国用户） |
| 离线 | 已下载内容可离线阅读；生词本本地优先、云端同步 |
| 兼容 | Web：Chrome/Safari/Edge 近 2 年版本；移动端：iOS/Android（后续） |
| 数据 | 生词、进度每日备份；支持导出生词本（CSV/Anki） |
| 合规 | 内容版权合规；用户数据隐私（不售卖）；未成年人模式（K12） |
| 成本 | MVP 阶段月度基础设施成本 < ¥300（详见技术选型文档） |

## 10. 成功指标

### 10.1 北极星指标
**周活跃学习者中，完成「阅读 ≥ 1 篇 + 复习 ≥ 1 次」的用户数（WAU 闭环完成率）。**

## 11. 里程碑与版本规划

| 阶段 | 周期 | 交付 | 验证目标 |
|---|---|---|---|
| **M0 内容流水线验证** ✅ | 第 1–2 周 | 抓中文内容 + pypinyin 注音 + 分词分级 → manifest/json → 推 Git 仓库、每日 Actions 定时 | **已达成**：能稳定每日产出内容 |
| **M0.5 分级校准 + 内容主线切换** | 第 3 周 | ① 分级改为 HSK 累积覆盖率阈值法；② 打通分级短文生产（300–600 字，按等级控词）；③ 新闻降为进阶挑战区 | **出关上闸**：同一批文章能产出真实的 2–5 级分布，且每级都有可读篇目 |
| **M1 MVP 阅读器** | 第 4–6 周 | Web 阅读器：读 Git raw JSON、点字拼音/释义、点词查义、整句翻译、注音开关 | 核心阅读体验可用，找 10–20 个种子用户试用 |
| **M2 生词本 + SRS** | 第 7–9 周 | 生词本、SRS 复习、学习统计、账户与同步 | 学习闭环跑通，验证留存 |
| **M3 内容扩充 + AI** | 第 10–13 周 | 公版经典规模化入库、AI 句子讲解、TTS 音频、搜索 | 内容厚度 + 体验提升 |
| **M4 多端 + 增长** | 第 14 周+ | App（iOS/Android）、分享、推荐优化 | 规模化 |

> **M0.5 是硬门槛**：分级不可信，M1 阅读器就只是「演示很好、用户读不懂」的壳。M0.5 未通过不启动 M1。

> 每个里程碑结束做一次用户访谈（≥ 5 人），决定下一步优先级。

## 12. 风险与待决问题

| # | 风险/问题 | 影响 | 应对 |
|---|---|---|---|
| R1 | 资讯内容版权（DMCA） | 高：仓库/服务可能被下架 | 优先公版 + RSS 摘要 + 自建；全文抓取仅限允许源；署名 |
